# 🌿 Serenity Plan

A modern **mental wellness and self-care web application** designed to help users manage their daily wellness activities in one place.

## 🚀 Live Demo

[Serenity Plan](https://serenity-plan.vercel.app/)

## ✨ Features

* 🔐 User Registration & Login
* 📊 Personal Wellness Dashboard
* 📝 Wellness & Activity Management
* 💳 Razorpay Payment Integration
* 📧 Email Notifications
* 🗄️ MySQL Database
* 📱 Responsive UI

## 🛠️ Tech Stack

**Frontend**

* React.js
* JavaScript
* CSS

**Backend**

* Node.js
* Express.js
* MySQL

**Deployment**

* Vercel – Frontend
* Render – Backend
* Aiven – MySQL Database

## 📂 Project Structure

```text
serenity-plan/
├── frontend/
└── backend/
```

## ⚙️ Installation

```bash
git clone https://github.com/devanshu091104/serenity-plan.git
cd serenity-plan
```

### Frontend

```bash
cd frontend
npm install
npm start
```

### Backend

```bash
cd backend
npm install
npm start
```
